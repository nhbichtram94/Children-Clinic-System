# Database

This folder contains the SQL Server database scripts for the Children's Clinic Management System.

## Database

- Database Name: QLKPN
- Database Management System: Microsoft SQL Server

## Main File

- QLKPN.sql – SQL script for creating the database schema, tables, relationships, and constraints.

## Main Modules

- User Management
- Patient Management
- Guardian Management
- Doctor Management
- Appointment Scheduling
- Medical Records
- Prescription Management
- Billing and Payment

The database is used by the C# WinForms application to manage clinic operations.
